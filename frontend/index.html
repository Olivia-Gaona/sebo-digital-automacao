Como este projeto acompanha a ementa

O material de cada item está na pasta docs/. O catálogo existe em três versões, uma para cada forma de levar conteúdo até o navegador:

  • No servidor Python (porta 8000), Catálogo é um arquivo pronto, sempre igual.
  • No servidor Node (porta 3000), Catálogo é montado pelo servidor a cada visita, e cada livro tem sua própria página, como Dom Casmurro.
  • No servidor Node, Catálogo via API chega vazio e é montado pelo navegador, com dados pedidos ao servidor.

No servidor Node, a Visão do robô mostra o que buscadores e redes sociais conseguem ler de cada página.
